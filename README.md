# Game Hub

Android game hub (Kotlin + Jetpack Compose).

Playable games:
- **Word Search** — themed letter grids, three difficulties
- **Water Sort** — pour colors between tubes, endless levels
- **Heartbound** — run an adventurer's guild in Lumenreach, and maybe fall for your heroes. v1.7 is the last gameplay stage: decorate the hall and hero rooms, private room visits, forge/library/garden/stables, hireable staff, crafting and enchanting, a traveling merchant with seasonal stock, seasons and weather, hero birthdays, a town map with date locations, a secret late hero (Nim Hale) with her own route, guild endings, and quietly animated portraits. Full-screen CGs, a gallery, and music/SFX are reserved for v1.8 so the APK stays small. v1.6 added turn-based battles, expeditions, bosses, branching chains, Iron Vesper, bond combos, and reputation. v1.5 added exclusive routes, group events, chapter 1, and fade-to-black cutaways, plus the v1.4 creation and QoL features.

Coming soon: 2048, Snake

Add games in `app/src/main/java/com/tim/gamehub/GameRegistry.kt`.

Build: `./gradlew assembleDebug`
