# Game Hub

Android game hub (Kotlin + Jetpack Compose).

Playable games:
- **Word Search** — themed letter grids, three difficulties
- **Water Sort** — pour colors between tubes, endless levels
- **Heartbound** — run an adventurer's guild in Lumenreach, and maybe fall for your heroes. v1.5 continues Heartbound: exclusive romance routes past the Heartbound bond (confession, proposal, and a per-partner ending), jealousy and rivalry, group events (lantern festival, shore day, harvest dance), injury caring scenes, a first chapter of the guild's history, optional fade-to-black cutaways, plus the v1.4 creation and QoL features.

Coming soon: 2048, Snake

Add games in `app/src/main/java/com/tim/gamehub/GameRegistry.kt`.

Build: `./gradlew assembleDebug`
