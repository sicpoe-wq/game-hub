# Game Hub

Android game hub (Kotlin + Jetpack Compose).

Playable games:
- **Word Search** — themed letter grids, three difficulties
- **Water Sort** — pour colors between tubes, endless levels
- **Heartbound** — run an adventurer's guild in Lumenreach, and maybe fall for your heroes. v1.4 adds character creation (name, look, pronouns, background + charm/wit/courage), three save slots with v1.3 migration, a relationship journal, daily summary, achievements, text speed / skip / dialogue log, expression portraits, and day/night backgrounds.

Coming soon: 2048, Snake

Add games in `app/src/main/java/com/tim/gamehub/GameRegistry.kt`.

Build: `./gradlew assembleDebug`
