# Game Hub

Android game hub (Kotlin + Jetpack Compose).

Playable games:
- **Word Search** — themed letter grids, three difficulties
- **Water Sort** — pour colors between tubes, endless levels
- **Heartbound** — run an adventurer's guild in Lumenreach, and maybe fall for your heroes. v1.6 adds turn-based battles you can watch or play (with an auto/manual toggle), multi-day expeditions with travel events, boss quests, branching quest chains, the rival Iron Vesper guild, bond combo attacks, and reputation that unlocks harder work. v1.5 added exclusive romance routes past the Heartbound bond (confession, proposal, and a per-partner ending), jealousy and rivalry, group events (lantern festival, shore day, harvest dance), injury caring scenes, a first chapter of the guild's history, and optional fade-to-black cutaways, plus the v1.4 creation and QoL features.

Coming soon: 2048, Snake

Add games in `app/src/main/java/com/tim/gamehub/GameRegistry.kt`.

Build: `./gradlew assembleDebug`
